Koneksi Database Google Spreadsheet

Tempel URL Web App Google Apps Script v2 (berakhiran /exec). Aplikasi akan menyimpan data ke dua sheet: Transaksi (17 kolom, termasuk pencatat & status verifikasi) dan AuditLog (jejak audit). Kode v2 otomatis menambahkan kolom baru saat doGet pertama dijalankan — data lama Anda tetap aman. Kosongkan untuk mode lokal/demo.

Panduan Setup Google Spreadsheet & Apps Script (v2)

1. Struktur Header Kolom Sheet Transaksi (17 kolom):

Sheet kedua bernama AuditLog dibuat otomatis oleh kode v2. Jika Anda punya sheet Transaksi lama, kolom baru akan ditambahkan otomatis oleh skrip.

2. Kode Google Apps Script (Code.gs) — v2:

3. Langkah Deploy di Google Apps Script:

Buka Spreadsheet Anda > menu Ekstensi > Apps Script > ganti seluruh isi Code.gs dengan kode v2 di atas > Terapkan (Deploy) > Deployment baru > Aplikasi web > Jalankan sebagai: Saya (Me) > Yang memiliki akses: Siapa saja (Anyone) > salin URL /exec ke menu Koneksi.

4. Migrasi Data Lama (otomatis):

Setelah URL v2 tersimpan, klik Sinkronkan. Skrip v2 akan menambahkan kolom Petugas, Dibuat_Pada, Status, Verifikator, Waktu_Verifikasi, Catatan_Edit pada sheet Transaksi lama dan membuat sheet AuditLog. Data lama otomatis berstatus "Terverifikasi (Data Lama)".
